# 海豚云路演故障备用方案

适用团队：**Team Falcons（MD0037）**

正式交付：**Web**

目标是在故障发生后 20 秒内作出明确切换，同时不伪造在线能力、成功状态或测试结果。备用材料只使用合成数据，不含密码、Token、真实学生信息或内部地址。

## 一、现场材料清单

- 最终 Web RC 的完整 commit SHA、构建时间和负责人确认记录。
- 一段 3–4 分钟的完整 Web 实机录屏，以及按教师、家庭、治理、AI 分段的短视频。
- 登录、教师班级切换、课件/作业、成绩单、三套分数、罚款指定撤销和 AI 离线状态的脱敏截图。
- 10 分钟讲稿、实机点击表、专家问答和本文件的本地只读副本。
- 已验收的上一份 Web 构建；不得在现场从未提交目录临时打包。
- 服务状态和故障联系人放在团队私密渠道，不写入公开仓库或投屏页面。

## 二、故障判定与切换

| 故障 | 10 秒内判定 | 现场动作 | 讲解口径 |
| --- | --- | --- | --- |
| 会议网络中断 | Web 地址和其他公网地址都无法访问 | 停止在线写入，播放完整 Web 录屏并使用静态截图 | “当前网络不可用，下面播放同一 RC 的预录路径；离线状态不代表后端写入成功。” |
| AI / Coze 离线 | 普通页面可用，AI 中心明确报未配置、超时或离线 | 保留错误状态，切回课件/作业/成绩或治理页面；需要时播放 AI 分段录屏 | “Coze 仅是运行时 AI 服务；普通业务不依赖 AI，也不会生成假答案。” |
| Supabase 或服务器故障 | 登录、数据读取或写入持续失败，AI 与普通页面同时受影响 | 停止重试写操作，播放完整录屏；用架构图说明 JWT、RLS、RPC 边界 | “当前服务端不可用，因此不宣称写入成功；展示的是同一版本已录制路径。” |
| Web 页面异常或白屏 | 仅当前标签页异常，网络与服务可访问 | 刷新一次；仍失败则打开预先准备的同 SHA Web 页面或切录屏 | “我们切换到同一 RC 的备用入口，不现场改代码。” |
| 数据状态不符合脚本 | 页面可用，但目标草稿、罚款单或角色范围缺失 | 不临时使用真实数据；跳过该写操作，展示已留存截图/录屏 | “此步骤需要预置合成状态，当前不执行，避免产生不可信演示结果。” |
| 登录身份不可用 | 指定合成账号登录失败 | 切换到已保持会话的备用浏览器配置；没有则播放对应角色片段 | “身份验证失败时不会绕过登录或权限。” |

## 三、20 秒主持人口令

### 网络中断

“现场网络暂时不可用。我们不会把离线页面描述为成功写入，现在切换到同一最终版本的 Web 录屏，继续展示六角色与权限闭环。”

### AI 离线

“AI 服务当前不可用，界面已经进入明确的离线状态，没有返回本地伪造结果。海豚云的普通教学和治理页面独立运行，我们继续展示成绩单或指定撤销。”

### 服务器故障

“当前后端连接异常，因此登录和写入无法可靠完成。系统不会把未知结果标成成功。我们切到预录证据，并说明服务端鉴权、RLS 和审计设计。”

## 四、备用录屏分镜

完整视频控制在 3–4 分钟，顺序与实机路径一致：

1. 登录教师端并切换第二个班级。
2. 展示课件、作业和成绩单整表发布。
3. 班级端查看教学内容、学生分排行与班级表现。
4. 家庭端只查看绑定学生的已发布成绩、学生分与海豚币。
5. 自治会端查看班级分。
6. 银行端结算罚款并对该记录指定撤销。
7. AI 中心展示当前范围查询、写操作草稿确认边界和离线状态。

录屏必须显示最终版本标识或同时保存其 SHA 说明；剪辑不得拼接不同数据环境后冒充一次连续操作。

## 五、禁止操作

- 不现场修改代码、数据库策略、角色分配或生产环境变量。
- 不关闭 RLS、不使用 service role 绕过普通用户权限。
- 不把浏览器缓存、静态 Mock 或口头描述包装成服务器成功结果。
- 不投屏密码管理器、终端环境变量、请求凭据、真实学生数据或内部管理地址。
- 不因某一步失败而声称整个回归已通过；只陈述已展示或有证据的部分。
- 不把 Android、iOS 或 Windows 产物作为本次正式交付；备用路径仍为 Web。

## 六、故障后记录

- 记录时间、最终 RC SHA、浏览器、网络/服务状态和受影响步骤。
- 对写请求记录脱敏 request ID 或操作 ID，不复制 Token、完整请求体或个人数据。
- 判断结果是“确认失败”“状态未知”还是“已由服务端回执成功”；状态未知时先查审计，不重复执行。
- 路演结束后创建缺陷记录，附脱敏复现和证据；不要在公开 Issue 粘贴凭据。
