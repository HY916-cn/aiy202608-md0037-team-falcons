# 07｜产品语言与视觉规范

**状态：强制执行**  
**版本：1.0**  
**适用范围：Web 产品、项目文档和路演材料**

任何开发者或 Codex 不得为同一概念自行创建同义名称、另一套颜色或另一枚图标。确需变化时先修改本文档并通过 Review。

## 1. 品牌固定名称

| 类型 | 固定写法 | 禁止替代写法 |
| --- | --- | --- |
| 中文产品名 | 海豚云 | 海豚校园、海豚云平台、Dolphin 云 |
| 英文产品名 | DolphinCloud | Dolphin Cloud、Dolphin-Cloud |
| AI 功能入口 | AI 中心 | AI 助手页、智能中心、DeepSeek 中心 |
| AI 角色名称 | 海豚助手 | DeepSeek 助手、机器人、小助手 |
| 吉祥物通称 | 海豚吉祥物 | AI 宠物、数字人 |
| 每日信息汇总 | 今日摘要 | 每日简报、今日概览、日报 |
| 项目虚拟币 | 海豚币 | 校园币、积分币、金币 |

DeepSeek 是技术提供方名称，只能出现在技术文档、设置或服务状态中；面向普通用户的界面统一显示“海豚助手”或“AI 中心”。

### 1.1 固定模式与品牌色

- 只支持一种界面模式：浅色模式 `light`。
- 不开发深色模式、自动跟随系统模式或不同角色主题。
- 品牌色只允许两种：主蓝色 `#1677FE` 与辅助青色 `#22D2ED`。
- 黑、白、灰只用于文字、页面背景、卡片和边框，不作为第三品牌色。
- 不使用紫、红、绿、黄、橙等额外业务色，不使用彩虹色或多色渐变。
- 主操作和当前导航使用主蓝色；AI、海豚和少量提示重点使用辅助青色。
- 不为六个角色分别设置颜色，角色依靠固定名称和图标识别。

### 1.2 固定网站图标

项目网站、PWA、浏览器标签页和应用图标统一使用同一个图标母版，正式名称为 **DolphinCloud Logo**。

固定规则：

1. 唯一母版使用设计交付的 480 × 480 SVG 原件，不重新绘制路径。
2. 图形只使用主蓝色 `#1677FE`、辅助青色 `#22D2ED` 与白色。
3. 所有栅格派生保持原始比例、路径和颜色，不增加阴影、描边、渐变或第三品牌色。
4. Web 与 PWA 派生图标由 CI 校验尺寸和文件内容；桌面端在最终主分支重建时同步，不在 Web 分支修改。

固定资源名称：

```text
assets/brand/dolphincloud-logo.svg       # 唯一母版
apps/client/assets/favicon-32.png        # 从母版生成
apps/client/assets/favicon-16.png        # 从母版生成
apps/client/assets/apple-touch-icon.png  # 从母版生成
apps/client/assets/pwa-icon-512.png      # 从母版生成
```

所有派生图标必须由同一 SVG 母版生成，禁止为 Web、手机和桌面端分别重新绘制。唯一母版已落在 `assets/brand/dolphincloud-logo.svg`；每次发布前检查各尺寸清晰度与文件哈希。

## 5. 固定动作词

| 场景 | 主按钮 | 次按钮或反向操作 |
| --- | --- | --- |
| 草稿 | 保存草稿 | 取消 |
| 内容发布 | 发布 | 撤回 |
| 课件发送 | 发送到班级 | 取消 |
| 文件回传 | 回传给教师 | 取消 |
| 学生／班级分 | 确认加分、确认扣分 | 取消 |
| 教师罚款 | 发起罚款 | 取消 |
| 银行处理 | 确认处理 | 拒绝 |
| 写操作预览 | 确认执行 | 返回修改 |
| 历史修正 | 撤销此操作 | 取消 |
| 已撤销恢复 | 恢复此操作 | 取消 |
| 删除普通草稿 | 删除草稿 | 取消 |

规则：

- 不使用含糊的“确定”“OK”“提交一下”。
- 主按钮应说明结果，例如“发布成绩”，而不是只有“提交”。
- 破坏性或反向操作不增加红色，统一使用深色文字、主蓝色描边、`TriangleAlert` 图标和明确确认文案。
- AI 写操作的按钮仍使用业务动作名称，不写“让 AI 执行”。

## 8. 图标规范

### 8.1 图标库

统一使用 Lucide：

- React Native / Expo：`lucide-react-native`。
- Web / Electron 复用同一语义封装，不允许混入 Emoji、系统图标或另一套图标库。
- 业务代码不得直接散落 import；统一通过 `AppIcon` 组件和语义映射表调用。

Lucide 官方说明其图标使用统一风格并支持颜色、尺寸和描边宽度自定义；本项目固定为线性风格、默认 `strokeWidth=2`。[Lucide 官方站点](https://lucide.dev/)

## 9. 两色浅色模式 Token

业务代码只能使用语义 Token，不直接使用十六进制颜色。

### 9.1 唯一品牌色

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `brand.primary` | `#1677FF` | 主按钮、当前导航、学生分、海豚币 |
| `brand.secondary` | `#22D3EE` | AI、海豚、班级分、待处理提示 |

### 9.2 结构中性色

中性色不表达角色或业务，只用于可读性和页面结构。

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `surface.page` | `#F8FAFC` | 唯一浅色页面背景 |
| `surface.card` | `#FFFFFF` | 卡片、对话框、输入框背景 |
| `text.primary` | `#0F172A` | 标题和正文 |
| `text.secondary` | `#64748B` | 次要说明 |
| `text.disabled` | `#94A3B8` | 禁用文字 |
| `border.default` | `#E2E8F0` | 普通边框和分隔线 |
| `surface.muted` | `#F1F5F9` | 中性标签、禁用背景 |

### 9.3 业务映射

| 语义 Token | 映射 | 区分方式 |
| --- | --- | --- |
| `score.student` | `brand.primary` | `Star` + “学生分” |
| `score.class` | `brand.secondary` | `ShieldCheck` + “班级分” |
| `coin.primary` | `brand.primary` | `Coins` + “海豚币” |
| `status.active` | `brand.primary` | 状态文字 + `CircleCheck` |
| `status.pending` | `brand.secondary` | 状态文字 + `Clock3` |
| `status.inactive` | `text.secondary` | 状态文字 + 对应图标 |
| `action.warning` | `text.primary` + `border.default` | `TriangleAlert` + 二次确认 |

禁止新增 `status.success`、`status.warning`、`status.danger` 等红绿黄 Token。失败、拒绝、撤销等状态必须通过固定文字、图标、边框与布局表达，不能通过增加第三种业务颜色表达。

## 10. 字体与排版

MVP 使用系统中文字体，避免增加字体包体积：

```text
iOS: PingFang SC / system
Android: Noto Sans CJK SC / sans-serif
Web/Windows: system-ui, "Microsoft YaHei", "PingFang SC", sans-serif
```

| Token | 字号 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| `text.xs` | 12 | 400/500 | 标签、辅助信息 |
| `text.sm` | 14 | 400/500 | 次要正文、表格 |
| `text.md` | 16 | 400/500 | 默认正文、输入 |
| `text.lg` | 20 | 600 | 卡片或区块标题 |
| `text.xl` | 24 | 700 | 页面标题 |
| `text.2xl` | 32 | 700 | 首页关键数字 |

正文行高至少为字号的 1.5 倍；不使用全大写英文作为中文界面的标题。

## 11. 间距、圆角与点击区域

- 基础网格：4 px。
- 常用间距：4、8、12、16、24、32 px。
- 移动端页面左右边距：16 px。
- Web 主内容最大宽度：1200 px。
- 卡片圆角：12 px。
- 输入框、按钮圆角：10 px。
- 标签圆角：999 px。
- 最小点击区域：44 × 44 px。
- 普通卡片阴影保持轻量；信息层级优先通过背景和边框表达。

## 12. 列表与表格

- 移动端使用卡片列表，不把宽表格强行压缩到手机。
- Web/EXE 可以使用表格，但首列固定为主要对象，操作列固定在末尾。
- 列表默认按最新时间倒序；排行按规则排序。
- 空列表必须显示明确原因和下一步，不显示空白页面。
- 涉及分值、成绩或币账时同时显示数值、原因、操作者和时间。

### 12.1 页面结构与去模板化规则

首页不得使用“4 个数据卡 + 4 个快捷操作卡 + 最新动态卡”的通用仪表盘模板。六个角色的首屏必须以其主要任务为核心，布局不得仅替换文字和图标。

| 端 | 首屏主视图 | 次要信息 | 禁止默认形式 |
| --- | --- | --- | --- |
| 教师端 | 可直接选学生的班级名册与点评工作区 | 课件、作业、成绩的紧凑工具条 | 一组统计卡片 |
| 班级端 | 课堂大屏式的日程、课件和班级公告 | 隐私安全的班级表现榜 | 小尺寸个人账户卡 |
| 家庭端 | 孩子当日时间线 | 一条成长指标带和待办作业 | 全班数据网格 |
| 银行端 | 罚款待办队列和账户搜索 | 币账流水与复核状态 | 宣传式数据大卡 |
| 自治会端 | 班级排行与当日检查面板 | 更正申请队列 | 和银行端相同的卡片结构 |
| 管理端 | 高密度账号、服务与权限表格 | 审计时间线 | 客户端式的快捷操作卡 |

结构硬性约束：

- 首屏最多只有 2 个主表面，不在卡片内再嵌套一组卡片。
- 关键指标使用单条 `InsightStrip` 或表格页头，不拆成等宽数据卡。
- 快捷操作使用页面工具条、列表行或对象详情侧栏，不使用“图标 + 标题 + 副标题 + 箭头”的重复入口卡。
- 同一屏内大圆角白色容器不超过 3 个；其余层级用留白、分割线、字号和行高表达。
- 图标只用于识别操作或状态，不为每个数值配一枚装饰图标或彩色图标底座。
- 页面不使用大段宣传口号、虚构百分比增长和无操作意义的“系统正常”大数字。
- Web/EXE 优先使用表格、分栏和侧边上下文；移动端把同一内容改为行列表，不简单将桌面卡片缩窄。

## 13. 确认与反馈

### 普通写操作

- 保存草稿等低风险操作可以直接执行并使用轻量 Toast。
- 发布、加减分、罚款、币账和撤销使用明确确认卡。

### 确认卡固定内容

1. 操作名称。
2. 作用对象。
3. 数值或状态变化。
4. 原因。
5. 影响说明。
6. 主动作与取消按钮。

### 撤销确认文案

标题：`撤销此操作？`  
说明：`系统不会删除原记录，而会新增一条反向记录。`  
主按钮：`撤销此操作`  
次按钮：`取消`

## 14. 海豚助手语言

海豚助手的语气：简短、友善、克制，不幼稚化学生，不替人作价值判断。

| 状态 | 固定示例 |
| --- | --- |
| 等待 | 需要我帮你找一下吗？ |
| 处理中 | 海豚助手正在处理…… |
| 待确认 | 这会改变数据，请确认对象和数值。 |
| 成功 | 完成了，操作记录已经保存。 |
| 失败 | 没有成功，原数据没有改变。 |
| DeepSeek 故障 | AI 暂时不可用，其他功能不受影响。 |

禁止用语：

- “这个学生很差／很优秀”。
- “你应该惩罚他”。
- “AI 已经替你决定”。
- “系统出错了哈哈”。

## 16. 无障碍与隐私

- 正文和背景满足常规可读对比度，不能只靠低对比灰色。
- 颜色不是唯一信息通道；分值同时显示正负号，状态同时显示文字。
- 图标按钮有可读标签，表单输入有标题与错误说明。
- 动画尊重系统“减少动态效果”设置。
- 班级公共端永不展示个人成绩、海豚币余额和罚款详情。
- 家庭端共享设备应支持快速退出并避免通知暴露敏感数值。
