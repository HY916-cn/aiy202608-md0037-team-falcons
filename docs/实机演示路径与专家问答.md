# 海豚云实机演示路径与专家问答

团队：**Team Falcons**｜编号：**MD0037**｜正式交付：**Web**

本文用于 10 分钟路演中的 3–4 分钟实机段落。所有身份和数据必须来自最终验收环境的合成数据，不在文档、屏幕共享或聊天中展示密码、Token、真实学生信息或内部地址。

## 一、演示前状态

- 浏览器使用最终 Web 地址，缩放 100%，提前关闭开发者工具、密码管理器提示和个人书签栏。
- 预先登录或准备好六角色的合成测试身份；账号信息通过团队批准的私密渠道保存，不写入仓库。
- 教师身份至少有两个授权班级，用于验证范围切换；两个班级分别准备可辨识的合成课件、作业和学生数据。
- 准备一张已发布成绩单、一张待处理罚款单和一条可被指定撤销的已结算记录。
- AI 路径只在服务端配置已验证时演示真实请求；否则演示离线边界并转普通页面。

## 三、演示员口令与操作纪律

- 每次角色或班级切换后，先念出页头范围，再点击业务入口；不要在旧页面未加载完时连续操作。
- 写操作先读出目标、影响范围和关键参数，再确认；危险操作展示二次确认。
- 如果提交按钮处于禁用、加载或错误状态，解释当前状态并按页面重试，不在控制台或数据库中临时改数据。
- 罚款撤销必须选择指定记录并填写原因；不把删除历史描述成撤销。
- AI 返回失败或离线时不重复编造提问结果，立即按备用方案切回普通页面。

## 四、专家问答

### Q1：为什么需要六个角色，而不是一个管理后台？

六个角色对应不同职责和数据范围。教师负责授权班级教学，班级端服务公共协作，家庭只能读取绑定学生，银行处理海豚币与罚款，自治会处理班级分，管理端负责账号、范围、审计和服务状态。差异同时存在于页面任务、服务接口和 RLS，不只是菜单隐藏。

### Q2：家庭端如何保证看不到其他学生？

客户端从当前 AuthRoleScope 选择绑定学生，服务端再根据 Supabase JWT、角色分配和家庭绑定关系执行 RPC/RLS。返回结果只包含当前学生的已发布数据；未发布草稿和其他学生行不应返回。客户端传入的用户 ID 或角色不作为授权依据。

### Q3：成绩、学生分、班级分和海豚币有什么区别？

成绩单用于教学评价；学生分记录个人成长；班级分记录集体表现；海豚币是校园激励账本。四者拥有不同模型、权限和记录，不自动换算，也不共享余额字段。

### Q4：为什么罚款撤销不直接删除或改回原记录？

删除会破坏审计和对账。指定撤销引用原操作并创建反向流水，保留操作者、原因、时间和前后状态；因此只影响被选择的操作，也能解释余额如何变化。

### Q5：AI 会不会绕过权限直接改数据？

不会。Coze 只作为服务端 AI Gateway 后的外部运行时服务。只读查询仍受当前会话和 RLS 约束；写请求只能生成 WriteActionPreview，用户确认后由普通业务服务重新鉴权和执行。客户端不提供可信 actorId、角色或授权范围。

### Q6：切换教师班级后，AI 会不会仍使用旧班级？

范围切换开始时旧上下文立即失效，界面清空旧消息、会话和待确认草稿，并在新范围验证完成前禁用输入。只有最后一次范围选择结果可以生效，旧请求返回也不能更新新范围页面。

### Q7：AI 或 Coze 不可用时，产品还能做什么？

课件、作业、成绩单、学生分、班级分、海豚币和罚款均由普通业务页面与 Supabase 服务完成，不依赖 AI。AI 未配置、超时或离线时只显示明确错误或离线状态，不生成本地假答案。

### Q8：为什么本次只交付 Web？

这是明确的最终提交边界。Web 能覆盖六角色和完整演示路径，也便于专家在浏览器访问。仓库中可能保留跨端工程或历史构建记录，但不把它们表述为本次正式交付。

### Q9：数据是否来自真实学校或真实学生？

不是。开发、测试和路演只使用合成数据。公开仓库、截图和视频不得包含真实姓名、学号、联系方式、账号密码、Token 或内部地址。

### Q10：如何证明页面上的成功不是本地假状态？

正式模式通过 Supabase 适配器调用安全 RPC，服务端成功后页面重新读取数据。写操作带确认、错误处理和必要的幂等/审计边界。演示时用跨角色读取、刷新后恢复和指定撤销后的流水变化证明数据已持久化；未配置服务时明确显示不可用。

### Q11：系统如何应对重复确认或网络重试？

确认过程有 pending 防护，服务端写操作使用幂等与状态检查。AI 草稿完成、取消或过期后不能重放；罚款等关键操作保留可审计回执。网络失败时页面显示失败，不把未知结果当作成功。

### Q12：当前还有哪些边界？

公网 HTTPS 地址、最终 RC SHA、真实 AI 网关联调和最终彩排结果都必须以提交时的验收记录为准。任何尚未完成的项目继续标为待确认，不用路线图替代已交付事实。
