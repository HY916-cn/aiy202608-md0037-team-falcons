# 海豚云五分钟演示脚本

队名：**Team Falcons**

> 当前状态：演示脚本骨架。尚未完成两次完整彩排、备用录屏和四端构建验收，本文件本身不代表 #25 已完成。

## 演示前 15 分钟

- 使用已记录完整 SHA 的 RC 构建，不现场拉取或临时改代码。
- 重置为合成演示数据，依次登录六角色确认会话可用。
- Web、Android、iOS 本地版和 Windows 班级端提前打开到登录页。
- 检查网络与 DeepSeek；本地保留备用录屏和静态项目介绍。

## 0:00—0:30｜问题与方案

“校园里课件、作业、评价、班级治理和校园币分散在多个工具。海豚云把教师、班级、家庭、银行、自治会和管理六个角色放进同一个应用，并通过严格权限连接同一份数据。”

强调三套独立体系：学生分、班级分、海豚币不会互相兑换；成绩也不计入学生分。

## 0:30—2:00｜教学闭环

1. 教师端选择班级，发送一份合成课件并发布作业。
2. 切到班级端，打开同一课件并看到作业；说明公共端不显示个人成绩、余额或罚款。
3. 切到家庭端，查看今日摘要、作业、已发布成绩和当前学生本人名次。

串词：“同一份业务数据按角色和班级范围展示，不靠复制页面或人工转发。”

## 2:00—3:25｜三体系与可追溯操作

1. 教师端为合成学生记录一次学生分变化，展示原因、操作者和时间。
2. 自治会端记录一次班级分并展示班级排行。
3. 银行端展示海豚币账户、流水和罚款单状态。
4. 操作中心选择指定历史操作预览撤销；强调系统新增反向流水，不删除原记录。

## 3:25—4:20｜AI 中心

1. 在 AI 中心查询当前角色范围内的今日事项。
2. 展示吉祥物的等待、待确认和完成反馈。
3. 如演示写操作，必须先展示客户端确认卡，再由海豚云服务执行；DeepSeek 不直接接触数据库或用户 JWT。

## 4:20—4:45｜故障降级

禁用或切断 DeepSeek 后展示固定反馈“AI 暂时不可用，其他功能不受影响”，随后从普通页面重复一个核心操作。

## 4:45—5:00｜多端交付与收尾

同时展示 Web、Android APK、iOS 本地测试版和 Windows EXE，说明四端复用 React + Expo 工程并读取同一后端。

收尾：“海豚云不是只会聊天的演示，而是一套普通功能完整、权限清晰、关键操作可审计并能安全接入 AI 的校园协作应用。”

## 备用切换

- DeepSeek 失败：立即切普通页面并播放 AI 备用片段。
- 网络失败：播放完整五分钟录屏，使用静态介绍说明架构。
- 演示数据异常：重新执行合成 seed；禁止临时使用真实学生数据。
- 某个构建无法启动：切 Web 完成同一流程，并明确该端已有带 SHA-256 的构建与验收记录。
