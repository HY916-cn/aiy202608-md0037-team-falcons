# 海豚云 · DolphinCloud

## 面向班级协作的校园应用与 DeepSeek AI 中心

> **把课件、作业、评价、成绩和校园银行放进一款应用，再让 AI 成为所有功能的自然语言入口。**

**项目类型：** AIY Hackathon 2026 Web 产品

**目标工期：** 黑客松冲刺版本

**交付形式：** 响应式 Web 应用
**应用形态：** 一套应用、六种角色界面、同一套数据

---

## 01｜项目简介

海豚云是一款面向教师、班级、家庭及校园组织的轻量校园协作应用。

它解决的不是某一个孤立问题，而是把校园中每天反复发生的小事集中起来：

- 教师需要把课件快速传到班级设备。
- 班级需要记录学生日常表现并查看班内排行。
- 教师需要发布作业、成绩和罚款通知。
- 家庭需要在一个入口了解学生当天的情况。
- 自治会需要管理各班级的集体分。
- 校园银行需要管理海豚币账户和每一笔流水。
- 管理人员需要统一维护账号、权限和操作记录。

所有核心功能都能通过普通页面完成；AI 中心通过服务端网关接入 DeepSeek，在当前用户权限范围内查询信息或生成待确认操作。即使 AI 暂时不可用，应用仍然可以正常运行。

### 一句话介绍

**海豚云是一款连接教师、班级、家庭与校园组织的日常协作应用，用户既可以点击操作，也可以让海豚 AI 助手帮助完成。**

## 02｜产品结构

### 六端合一

“六端”不是六套独立应用，而是同一套 React + Expo 应用根据账号身份展示不同界面。这样既能覆盖完整校园场景，也能缩短黑客松开发和交付时间。

| 端 | 使用者 | 核心职责 |
| --- | --- | --- |
| 教师端 | 任课教师、班主任 | 传课件、管理学生分、发布作业与成绩、发起罚款 |
| 班级端 | 班级公共设备、授权班干部 | 接收课件、管理学生分、展示班内排行与班级信息 |
| 家庭端 | 学生与家长 | 查看个人学生分、作业、成绩、罚款和海豚币 |
| 银行端 | 校园银行工作人员 | 管理海豚币账户、流水、罚款扣款与账务撤销 |
| 自治会端 | 学生自治会成员 | 对班级集体表现加减班级分、填写检查原因 |
| 管理端 | 学校管理员 | 管理账号、班级、权限、规则、审计与异常处理 |

### 家庭端设计

学生端与家长端合并为“家庭端”，减少重复开发：

- 学生登录后查看自己的信息。
- 家长绑定学生后查看对应学生的信息。
- 同一家庭可切换已绑定的孩子。
- 家长只能查看，涉及兑换、申诉等操作时按权限单独控制。

### 班级端设计

班级端主要运行在教室电脑、智慧屏或班级公共平板上：

- 登录班级公共账号后接收教师课件。
- 授权班干部可进行学生分操作。
- 所有操作必须记录实际操作人，不能只记录“班级账号”。
- 公共屏幕默认只显示必要信息，个人成绩、海豚币和罚款不公开。

## 03｜三套独立体系

海豚云包含三套不同的数值体系。三者分别记账、分别排行，不自动互相换算。

| 体系 | 含义 | 管理端 | 查看端 | 是否参与班内排行 |
| --- | --- | --- | --- | --- |
| 学生分 | 学生在课堂、作业、纪律、卫生和活动中的日常表现分 | 教师端、班级端 | 教师端、班级端、家庭端 | 是 |
| 班级分 | 自治会对整个班级的卫生、纪律、活动等集体表现评分 | 自治会端 | 教师端、班级端 | 否，本期只展示本班记录与趋势 |
| 海豚币 | 校园银行管理的虚拟币，用于奖励、扣款和校园活动 | 银行端 | 教师端、家庭端 | 否 |

### 体系边界

- 学生成绩是教学结果，不等于学生分。
- 学生分不能自动兑换成海豚币。
- 班级分属于班级集体，不分摊到个人。
- 海豚币只用于校内虚拟激励，不接入真实货币或支付。
- 所有变化都必须保留原因、操作者、时间和关联对象。

## 04｜核心功能

### 4.1 教师与班级之间的课件传输

课件传输只围绕教师和班级公共端展开，不做个人网盘。

**教师端：**

- 上传 PDF、图片、Word、PPT 或压缩包。
- 选择目标班级，填写标题、科目和说明。
- 查看班级端是否接收或下载。
- 更新课件版本或撤回仍在有效期内的课件。

**班级端：**

- 接收教师发送的课件并按日期、科目查看。
- 下载、投屏或打开课件。
- 将课堂产生的图片、资料等文件回传给指定教师。

**本期边界：** 不制作个人聊天、永久网盘和复杂在线预览。

### 4.2 学生分与班内排行

**教师端与班级端可以：**

- 对一名或多名学生加分、扣分。
- 选择课堂、作业、纪律、卫生或活动等项目。
- 填写分值、原因和备注。
- 查看学生分变化记录。
- 选择指定历史记录进行撤销。

**排行展示：**

- 教师端和班级端显示班级内学生分排行。
- 家庭端只显示本人总分、本人名次和个人记录。
- 可按本周、本月或全部时间查看。
- 同分学生显示并列名次。
- 管理端可以关闭公共屏幕上的姓名展示，改为昵称或学号尾号。

### 4.3 班级分

**自治会端可以：**

- 选择被检查班级。
- 按卫生、纪律、活动或其他项目加减班级分。
- 填写检查原因并上传一张凭证图片。
- 查看自己提交的记录并申请更正。

**教师端与班级端可以：**

- 查看本班班级分总值。
- 查看每条加减分记录和近期变化趋势。
- 对有疑问的记录提交申诉。

本期由管理端处理申诉，不制作复杂的多级审批流。

### 4.4 作业发布

**教师端：**

- 选择班级和科目，填写作业内容、截止时间。
- 添加图片或附件。
- 发布、修改或撤回作业。

**家庭端：**

- 查看待完成、即将截止和已结束的作业。
- 标记“已知晓”或“已完成”。

**班级端：**

- 展示当天作业清单，方便教室统一查看。

本期只做作业发布与查看，不做在线提交、批改和查重。

### 4.5 成绩发布

**教师端：**

- 创建考试或测验项目。
- 录入学生成绩并检查后统一发布。
- 在发布前预览接收范围。
- 修改错误成绩并保留修改记录。

**家庭端：**

- 只能查看本人或已绑定孩子的成绩。
- 查看科目、分数、教师评语和发布时间。

**隐私规则：** 班级公共端不展示个人成绩排行，成绩也不计入学生分。

### 4.6 罚款功能

罚款使用海豚币，不涉及真实货币。

1. 教师选择学生、罚款项目、海豚币金额和原因。
2. 系统按银行端配置的项目和金额上限校验。
3. 教师确认后生成罚款单，并写入海豚币流水。
4. 家庭端收到通知，可查看原因和扣款记录。
5. 银行端负责查账、异常处理和撤销；管理端可以审计。

若余额不足，系统保留“待处理罚款单”，不允许账户直接变成负数。教师只能在授权范围内发起罚款，不能自由修改海豚币余额。

### 4.7 校园银行

**银行端可以：**

- 按姓名、学号或班级查询账户。
- 发放、扣除或调整海豚币。
- 查看罚款单和完整账户流水。
- 选择指定历史账务进行撤销。
- 查看异常余额和重复操作提示。

**教师端可以：**

- 查看所教学生的海豚币余额。
- 发起授权范围内的奖励或罚款。

**家庭端可以：**

- 查看余额、奖励、罚款和调整流水。
- 查看每笔变化的来源与原因。

## 05｜指定操作撤销

撤销不是“只能撤销最近一次”，而是统一的操作记录中心。

### 使用方式

- 按时间、学生、班级、操作类型或操作人筛选记录。
- 打开某一条记录，预览撤销后的影响。
- 选择这条指定记录并填写撤销原因。
- 每次可以撤销一条历史操作，也可以连续撤销多条不同记录。
- 如果需要恢复已撤销的操作，可对“撤销记录”再次执行反向操作。

### 适用范围

- 学生分加减记录。
- 班级分加减记录。
- 海豚币发放、扣除与罚款记录。
- 作业发布和成绩发布状态。
- 课件发送记录。

### 安全原则

- 撤销不会删除原记录，而是新增一条方向相反的修正记录。
- 撤销后总分和余额必须重新计算。
- 海豚币账务由银行端或管理端撤销。
- 班级分由自治会端或管理端撤销。
- 成绩修改始终保留旧值和新值。
- 所有撤销都记录操作者、时间、原因和目标操作编号。

## 06｜DeepSeek AI 中心

AI 中心是普通功能之外的统一对话入口。用户可以点击按钮完成业务，也可以直接告诉海豚助手自己想做什么。

### 示例对话

- 教师：“把刚上传的数学课件发送给七年级二班。”
- 教师：“给王同学课堂表现加 3 分，原因是主动回答问题。”
- 教师：“给李同学发起 2 枚海豚币罚款，原因是未归还器材。”
- 班级：“今天老师发了哪些课件和作业？”
- 家庭：“总结一下我今天的作业、分数变化和海豚币变化。”
- 银行：“查找这笔罚款对应的流水。”
- 自治会：“给七年级二班卫生加 5 分。”
- 管理员：“查找今天被撤销的操作。”

### 海豚云 AI 能力

DeepSeek 只返回白名单意图，海豚云服务端负责权限校验、数据查询和操作草稿，不向模型开放数据库。

| AI 能力 | 可用角色 | 写操作确认 |
| --- | --- | --- |
| 查询课件、作业和今日安排 | 教师、班级、家庭 | 不需要 |
| 查询学生分、班内名次和记录 | 教师、班级、家庭 | 不需要 |
| 查询班级分与记录 | 教师、班级、自治会 | 不需要 |
| 查询成绩 | 教师、对应家庭 | 不需要 |
| 查询海豚币余额与流水 | 教师、对应家庭、银行 | 不需要 |
| 发送课件或发布作业 | 教师 | 需要 |
| 给学生加减分 | 教师、授权班级操作者 | 需要 |
| 给班级加减分 | 自治会 | 需要 |
| 发布成绩或发起罚款 | 教师 | 需要 |
| 调整海豚币或撤销账务 | 银行、管理端 | 需要 |

### AI 操作规则

1. DeepSeek 识别用户需求并返回白名单意图。
2. 海豚云服务根据登录账号重新检查角色和数据范围。
3. 查询操作直接显示结果。
4. 写操作先显示对象、数值、原因和影响预览。
5. 用户点击确认后才真正执行。
6. 结果生成唯一操作编号并进入审计记录。
7. 海豚吉祥物反馈处理中、成功、警告或失败。

相同请求编号不能重复执行，避免重复加分、重复发布或重复扣款。

## 07｜海豚吉祥物与今日摘要

### 海豚吉祥物

海豚既是 AI 中心的形象，也会在普通操作中提供轻量反馈。

| 状态 | 示例反馈 |
| --- | --- |
| 等待 | “需要我帮你找一下吗？” |
| 处理中 | “小海豚正在处理……” |
| 待确认 | “这会改变数据，请确认对象和数值。” |
| 成功 | “完成啦，操作编号已经保存。” |
| 失败 | “没有成功，原数据没有改变。” |
| 提醒 | “你有一项作业即将截止。” |

吉祥物采用图片、表情切换和简单动效，不制作复杂 3D 或语音系统。

### 今日摘要

| 角色 | 今日摘要内容 |
| --- | --- |
| 教师 | 已发课件、作业、成绩、学生分变化、罚款和待处理事项 |
| 班级 | 今日课件、作业、学生分变化、班级分变化和班内排行 |
| 家庭 | 本人作业、成绩发布、学生分与名次、海豚币和罚款变化 |
| 银行 | 今日发放、扣款、罚款、撤销和异常流水 |
| 自治会 | 今日检查班级、班级分变化和待处理申诉 |
| 管理端 | 活跃情况、异常操作、撤销记录和系统提醒 |

今日摘要只总结已经发生的事实，不自动评价学生好坏，也不自动执行写操作。

## 08｜权限与隐私

| 数据或操作 | 教师端 | 班级端 | 家庭端 | 银行端 | 自治会端 | 管理端 |
| --- | --- | --- | --- | --- | --- | --- |
| 课件传输 | 发送、接收 | 接收、回传 | 不开放 | 无 | 无 | 审计 |
| 学生分 | 管理、查看 | 授权管理、查看 | 查看本人 | 无 | 无 | 配置、审计 |
| 班级分 | 查看本班 | 查看本班 | 不开放 | 无 | 管理 | 配置、审计 |
| 作业 | 发布 | 展示 | 查看 | 无 | 无 | 审计 |
| 成绩 | 发布 | 不展示个人成绩 | 查看本人 | 无 | 无 | 审计 |
| 海豚币 | 查看、发起奖励或罚款 | 不开放 | 查看本人 | 管理 | 无 | 配置、审计 |
| 指定撤销 | 本人业务范围 | 本人业务范围 | 无 | 币账范围 | 班级分范围 | 全局异常处理 |

所有用户只能访问自己角色和所属班级范围内的数据。公共班级端不得展示个人成绩、海豚币余额或罚款详情。

## 10｜两周演示版计划

### 第 1—2 天｜应用框架

- 建立 Expo 项目、登录和六种角色权限。
- 准备班级、教师、学生、家庭关系和演示数据。
- 完成六端首页和统一导航。

### 第 3—5 天｜校园核心业务

- 完成教师与班级课件传输。
- 完成学生分、班内排行和班级分。
- 完成作业发布、成绩发布和家庭端查看。

### 第 6—7 天｜银行与操作记录

- 完成海豚币账户、奖励、罚款和流水。
- 完成指定历史记录撤销与权限校验。
- 完成各角色今日摘要。

### 第 8—9 天｜AI 与吉祥物

- 接入 DeepSeek AI 中心和海豚云 AI Gateway。
- 完成查询、写操作确认和结果卡片。
- 接入海豚吉祥物的状态反馈。

### 第 10 天｜交付与演示

- 输出可部署的响应式 Web 版本。
- 检查六个演示账号和同一份共享数据。
- 准备十分钟路演、3—4 分钟实机流程、备用视频和项目介绍材料。

### 工期成立的条件

- 六端共用一套工程，只根据角色切换页面和权限。
- 只实现黑客松演示闭环，不制作在线作业批改、真实支付和多级审批。
- 由 2 名开发成员和 1 名界面／测试成员协作。
- 如果只有 1 名开发成员，优先保留普通页面和 AI 查询，将部分 AI 写操作改为演示卡片。

## 11｜黑客松演示闭环

1. **课件到班：** 教师端上传数学课件，班级端立即接收并打开。
2. **课堂评价：** 班级端给学生加分，班内排行实时变化。
3. **集体评价：** 自治会端给该班卫生加分，教师端看到班级分变化。
4. **家庭协同：** 教师发布作业和成绩，家庭端查看今日摘要。
5. **校园银行：** 教师发起海豚币罚款，银行端看到流水，家庭端收到通知。
6. **精准纠错：** 银行端选择刚才的指定罚款记录撤销，余额自动恢复，原记录仍可追溯。
7. **AI 操作：** 教师通过 DeepSeek 说“给王同学课堂表现加 3 分”，确认后完成操作。
8. **多设备体验：** 展示桌面和手机浏览器读取同一份数据。

## 12｜验收标准

- DeepSeek 不可用时，所有普通页面仍可完成核心业务。
- 教师端发送课件后，指定班级端可以查看、下载并回传文件。
- 学生分、班级分和海豚币独立记录，不发生混算。
- 教师端与班级端可以看到班内学生分排行，家庭端只能看到本人信息。
- 教师可以发布作业和成绩，家庭端只能查看绑定学生的数据。
- 教师可以按规则发起海豚币罚款，银行端能查看对应流水。
- 用户能从历史记录中选择指定操作撤销，而不只撤销最近一次。
- 撤销不会删除原记录，分值与余额计算正确。
- 每个 AI 写操作均经过身份校验、影响预览和人工确认。
- 六种角色界面权限正确，公共班级端不泄露个人敏感信息。
- Web 在桌面和手机宽度下均能完成主演示流程。

## 13｜项目亮点

1. **真实需求：** 课件、作业、评价、成绩和校园银行都是校园每天会发生的场景。
2. **六端协作：** 教师、班级、家庭、银行、自治会和管理端共享一套可信数据。
3. **三套体系清晰：** 学生分、班级分、海豚币各自管理，避免概念混乱。
4. **AI 不是摆设：** DeepSeek 识别真实业务意图，服务端保留权限、确认和审计。
5. **纠错能力：** 用户可以选择任意符合权限的历史操作撤销，而不是只能后悔一次。
6. **易于交付：** 一套 React + Expo Web 工程覆盖桌面、平板和手机浏览器。
7. **有温度的反馈：** 海豚吉祥物贯穿普通操作和 AI 操作，让系统更亲切。

## 最终介绍

海豚云不是一个只有聊天框的 AI Demo，而是一款可以独立使用的校园应用。

它以教师和班级之间的课件传输为基础，连接学生分、班级分、海豚币、作业、成绩和罚款等校园事务；通过家庭端让学生和家长共享同一个信息入口，通过银行端、自治会端和管理端建立清晰的职责边界。

DeepSeek AI 中心让用户可以用自然语言查找信息或发起操作，海豚云 AI Gateway 负责权限控制和服务调用，海豚吉祥物则在每一步提供直观反馈。

> **海豚云——让校园事务更清楚，让协作更简单，让 AI 真正参与日常。**
